#  Botão Simulator

Aplicativo mobile desenvolvido em React Native com Expo, que simula um botão interativo. A cada clique, o botão aumenta de tamanho, o contador é incrementado e sua aparência muda aleatoriamente.

##  Sobre o projeto

O Botão Simulator é um aplicativo de botão único, desenvolvido com o objetivo de praticar conceitos de desenvolvimento mobile utilizando React Native.

O aplicativo possui uma interface simples e interativa, onde o usuário pode pressionar um botão e visualizar mudanças na tela a cada interação.

##  Funcionalidades

- Contador de cliques.
- Botão que aumenta de tamanho a cada clique.
- Mudança aleatória de cor ou aparência do botão.
- Interface simples e intuitiva.
- Interação dinâmica com o usuário.

##  Tecnologias utilizadas

- React Native
- Expo
- JavaScript / TypeScript

##  Demonstração

O aplicativo apresenta um botão interativo que modifica seu tamanho e aparência conforme o usuário realiza cliques.
